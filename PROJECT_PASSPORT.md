📋 Паспорт проекта: PvzPrinter

1. Суть и философия
* Продукт: Бесплатный десктопный инструмент для сотрудников ПВЗ Ozon. Автоматически печатает этикетки ячеек при сканировании посылки, предоставляет гибкие настройки формата и фона.
* Философия: Удобство и приватность > прибыль. Опыт разработки > масштаб. Инструмент создаётся для решения реальной боли, а не для заработка.
* Целевая аудитория: Сотрудники ПВЗ, работающие с приёмкой заказов Ozon (сканер → сайт показывает ячейку → печать).
* Ключевое ограничение: Приложение не заменяет официальный софт Ozon. Это вспомогательный инструмент.
* Монетизация: Отсутствует. Проект бесплатный и открытый. Донаты принимаются исключительно по желанию и возможности пользователей, без каких-либо обязательств или привязки к функционалу.
* Приватность: Полная. Никакой телеметрии, никаких серверов, никаких HWID. Все данные хранятся только локально.

4. Выбор технологий
Компонент       Технология
GUI             WPF
Обоснование:    Нативный Windows, богатые возможности стилизации, зрелая экосистема. Идеально для десктопного инструмента под Windows. Avalonia — запасной вариант, если понадобится кроссплатформа. WinForms — НЕ рекомендуется (устарел, слабая стилизация).

Компонент                   Технология  
IPC (расширение ↔ десктоп)  WebSocket
Обоснование:                Универсальный протокол, поддерживается всеми браузерами без плагинов. Named Pipe требует нативных модулей в расширении, что усложняет разработку. WebSocket проще в отладке и портировании.

Компонент       Технология      Обоснование:
Конфигурация    settings.json
Обоснование:    Читаемый формат, удобная сериализация через System.Text.Json. Заменяет printer.txt.

Компонент       Технология              Обоснование:
Логирование     Файловый (logs/app.log)
Обоснование:    Простота, ноль внешних зависимостей. Ротация по размеру (5 МБ) и дате. Serilog/NLog — позже при необходимости.

Компонент       Технология              
Язык            C# / .NET 8+
Обоснование: LTS-версия, актуальная для WPF и Minimal API

5. Функция: Фон этикетки
Хранение:
Дефолтные фоны: папка /backgrounds/default/ рядом с PvzPrinter.exe. Поставляются с программой. Могут обновляться при обновлениях.
Пользовательские фоны: любая папка по выбору пользователя. Программа не управляет ими.
Выбор в GUI: стандартный OpenFileDialog (фильтр *.png, InitialDirectory = /backgrounds/default/).
Превью: отсутствует в приложении. Пользователь видит превью через нативный функционал проводника Windows (режимы «Плитка», «Крупные значки»).

settings.json:
{
  "backgroundImage": "C:\\Users\\Ivan\\Pictures\\my_logo.png",
  "backgroundType": "custom"
}

Для дефолтных: относительный путь (backgrounds/default/white.png)
Для пользовательских: абсолютный путь
При переносе на другой ПК пользовательские фоны нужно выбрать заново. Это осознанный компромисс ради простоты и прозрачности.

Параметр                Значение
Формат                  PNG
Масштабирование         Stretch (растягивать под размер этикетки)
Лимит размера файла     500 КБ
Лимит разрешения        1000x1000 px
Обработка ошибок        Тихий fallback на дефолтный фон + запись в лог

6. Поток данных при печати
[Страница Ozon в браузере]
        ↓ (DOM-мониторинг через MutationObserver)
[content.js в расширении]
        ↓ (WebSocket сообщение с номером ячейки)
[IpcServer в PvzPrinter.Desktop]
        ↓ (вызов IPrinterService)
[PvzPrinter.Core → LabelPrinter]
        ↓
[Принтер печатает этикетку]
